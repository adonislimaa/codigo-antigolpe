# Código Antigolpe · Adonis Lima Advocacia

Gerador do código de segurança do cliente, contra o golpe do falso advogado.

- Página única (`index.html`), publicada pelo GitHub Pages.
- Gera códigos no formato palavra + número e imprime o termo no timbrado do escritório.
- Nenhum código se repete: cada código é conferido num registro central privado, que guarda só o código e a data.
- Nome e CPF do cliente nunca são salvos nem enviados.
